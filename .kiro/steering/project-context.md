## When the idea is chosen

1. Define the target user, problem, single demo workflow, and MVP acceptance criteria.
2. Use Kiro to create the scoped requirements, design, and tasks under `.kiro/specs/`.
3. Choose the smallest suitable stack and only the integrations the demo needs.
4. Build and verify an end-to-end slice early, then add the remaining MVP tasks.
5. Update this context and the README to reflect the actual implementation and Kiro usage.

The shared ChatGPT planning Page contains event logistics. Its contents and chat histories are not automatically synchronized into this repository; copy relevant product decisions into version-controlled context as they are made.
