# Coordinator workspace

The approved workflow is the visual authority. A coordinator uses this desktop workspace alongside a chart in a brightly lit clinic; light surfaces and readable text take priority over dramatic effects.

## System
- Canvas #f5f6fa, surface #ffffff, ink #242b3f, secondary #62697b, line #e2e5ed, action violet #5a4bb7.
- A compact dark navigation rail grounds the workspace. Violet denotes navigation and actions; green, amber and red appear only with textual status labels.
- Headings use Avenir Next with system fallback; body uses the native system UI stack. Monospace is reserved for registry identifiers, chart line IDs and measurements.
- Dense but readable rows, generous section separation, quiet one-pixel dividers. Avoid decorative metrics or unrelated imagery.
- Main content and evidence sit beside one another. On smaller screens the evidence panel follows the selected row; navigation becomes a horizontal bar.
- Controls use 8px corners; containers 12px. Focus rings are visible. Hover does not move layout. Respect reduced motion.

## Signature
A selected patient opens an evidence ledger: each finding retains its quoted chart line, observation date and reason. Missing information is as visible as supported findings.

## Product states
Initial state is unapproved, with the criteria review as the primary action. No fabricated results populate the worklist. Fixture mode is labeled throughout. Running, failed and stale screenings provide explicit next actions.
